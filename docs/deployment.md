# Развёртывание petChess

Для бесплатного размещения используется один веб-сервис Render и отдельная
PostgreSQL-база Neon. Образ из корневого `Dockerfile` собирает фронтенд и
бэкенд вместе. Render предоставляет HTTPS и адрес вида `*.onrender.com`.

## 1. Создать пустую базу Neon

Создайте проект PostgreSQL на бесплатном плане в [Neon](https://console.neon.tech/).
Сохраните хост, имя базы, пользователя и пароль из окна подключения.
В Render они понадобятся как отдельные переменные окружения:

- `DB_URL` — `jdbc:postgresql://HOST/DATABASE?sslmode=require`
- `DB_USERNAME` — пользователь Neon
- `DB_PASSWORD` — пароль пользователя Neon

Не включайте пароль в `DB_URL` и не сохраняйте его в репозитории.
Для этого развёртывания создаётся новая пустая база. При первом запуске
Spring Boot создаст таблицы `users`, `games` и `moves`.

## 2. Развернуть веб-сервис Render

В [Render Dashboard](https://dashboard.render.com/) выберите **New → Blueprint**,
подключите репозиторий `almute4/petChess` и выберите ветку `main`.
Файл `render.yaml` задаёт один бесплатный Docker веб-сервис.
При создании Blueprint Render запросит `DB_URL`, `DB_USERNAME` и
`DB_PASSWORD`. Значение `JWT_SECRET` Render сгенерирует самостоятельно.

После сборки проверьте адрес сервиса. Если адрес не оканчивается на
`.onrender.com` или вы используете собственный домен, укажите точный
HTTPS-адрес в переменной `APP_ALLOWED_ORIGIN` и перезапустите сервис.

## 3. Проверить опубликованную версию

1. Откройте адрес сервиса по HTTPS. Страница входа должна загружаться.
2. Зарегистрируйте два разных аккаунта в обычном окне и инкогнито.
3. Создайте партию, присоединитесь вторым игроком и сделайте ходы обоими цветами.
4. Обновите обе страницы, проверьте сохранение позиции и истории.
5. Проверьте сдачу или мат и запись результата в истории.
6. Проверьте переподключение после временного обрыва сети.

Бесплатный сервис Render засыпает после 15 минут без входящих HTTP-запросов
или WebSocket-сообщений. Первое открытие после простоя может занять около минуты.
Neon хранит данные отдельно от веб-сервиса, поэтому его перезапуск не удаляет
аккаунты и партии.
