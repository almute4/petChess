# Публичное развёртывание petChess

Публичная версия доступна по адресу [pet-chess.hostless.app](https://pet-chess.hostless.app).
Приложение собрано из корневого `Dockerfile` в одном сервисе Hostless. База
PostgreSQL размещена отдельно в Neon. Для новых развёртываний можно использовать
бесплатные тарифы обоих сервисов без переноса локальных аккаунтов и партий.

## База Neon

1. Создайте проект PostgreSQL на бесплатном плане [Neon](https://console.neon.tech/).
2. В **Connect** выберите базу и роль. Для постоянно работающего Spring Boot
   сервиса можно выключить **Connection pooling**.
3. Откройте пароль кнопкой **Show password** и скопируйте параметры подключения.
   Проверьте, что вместо пароля не скопирована маска из звёздочек.

Пароль не должен попадать в исходный код, `render.yaml` или Git. Новая база
пустая; Spring Boot создаёт таблицы при первом успешном запуске.

## Приложение Hostless

1. Создайте аккаунт в [Hostless](https://hostless.cloud/) и подключите только
   репозиторий `almute4/petChess` через GitHub.
2. Создайте **App** из ветки `main`. Укажите имя `pet-chess`, корневую рабочую
   директорию `/`, сборку **Docker** и путь `Dockerfile`.
3. Выберите один экземпляр размера **Standard (0.5 vCPU, 1024 MB)**. Он
   укладывается в бесплатный лимит аккаунта. Установите HTTP health check `/`.
4. В **Settings → Environment variables** сохраните переменные ниже.
   После сохранения запустите **Deploy changes**.

| Переменная | Значение |
|---|---|
| `SPRING_PROFILES_ACTIVE` | `prod` |
| `DB_URL` | `jdbc:postgresql://HOST/DATABASE?sslmode=require` |
| `DB_USERNAME` | роль Neon |
| `DB_PASSWORD` | пароль роли Neon |
| `JWT_SECRET` | случайный секрет не короче 32 байт |
| `APP_ALLOWED_ORIGIN` | `https://pet-chess.hostless.app` |
| `JAVA_TOOL_OPTIONS` | `-XX:MaxRAMPercentage=60.0 -XX:ActiveProcessorCount=2` |

При смене домена обновите `APP_ALLOWED_ORIGIN`. Hostless задаёт `PORT`, а
приложение слушает этот порт. Включён автоматический деплой новых коммитов
ветки `main`.

## Проверка

1. Откройте публичный адрес по HTTPS и зарегистрируйте двух игроков в разных
   сеансах браузера.
2. Создайте партию, присоединитесь вторым игроком и сделайте ходы обоими цветами.
3. Обновите страницу: позиция и история ходов должны восстановиться из Neon.
4. Завершите партию сдачей или матом и проверьте результат в **Match History**.
5. `GET /api/games` без токена должен вернуть HTTP 401.

В корне репозитория сохранён `render.yaml` как альтернативная конфигурация для
Render. Его бесплатный план может потребовать карту для проверки аккаунта.
